# Badminton Manager (Next.js + Supabase)

1. Tạo project Supabase, chạy `supabase/schema.sql` trong SQL Editor.
2. Copy `.env.local.example` -> `.env.local`, điền URL + anon key.
3. `npm install` rồi `npm run dev` -> http://localhost:3000
4. Deploy: đẩy lên GitHub -> import vào Vercel, thêm 2 biến môi trường như bước 2.

Chi tiết xem trong hướng dẫn trò chuyện.
